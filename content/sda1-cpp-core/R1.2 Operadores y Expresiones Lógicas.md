>[!question] A102(CE2) Ecuaciones de segundo grado
> En las clases de Matemáticas has aprendido a resolver analíticamente ecuaciones de segundo grado de la forma:
>$$ax^2 + bx + c = 0$$
>Para encontrar los valores de $x$ que satisfacen la igualdad, se emplea la fórmula general:
>$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
>La expresión situada dentro de la raíz cuadrada se denomina **discriminante** ($\Delta$):
>$$\Delta = b^2 - 4ac$$
>El valor del discriminante determina el comportamiento de las soluciones de la ecuación:
>
>1. **Si $\Delta > 0$**: La ecuación posee **dos soluciones reales distintas** ($x_1$ y $x_2$).
 >2. **Si $\Delta = 0$**: La ecuación posee **una única solución real doble** ($x_1 = x_2 = -b / (2a)$). 
>3. **Si $\Delta < 0$**: La raíz cuadrada de un número negativo no tiene solución en el conjunto de los números reales (las raíces son complejas/imaginarias).
>**Código base de partida**
>``` cpp
>/*CALCULADORA DE ECUACIONES DE SEGUNDO GRADO*/
>#include <iostream>
>#include <cmath>
>
>int main() {
 >   double a, b, c, discriminante, x1, x2;
>
 >   // Cabecera del programa
 >   std::cout << "CALCULADORA DE ECUACIONES DE SEGUNDO GRADO\n";
 >   std::cout << "==========================================\n";
>
 >   // Solicitar al usuario los coeficientes de la ecuación
 >   std::cout << "Ingrese el coeficiente a: ";
 >   std::cin >> a;
 >   std::cout << "Ingrese el coeficiente b: ";
 >   std::cin >> b;
 >   std::cout << "Ingrese el coeficiente c: ";
 >   std::cin >> c;
>
 >   // Ecuacion de segundo grado: ax^2 + bx + c = 0
 >   std::cout << "La ecuación es: " << a << "x^2 + " << b << "x + " << c << " = 0\n";
>
 >   // =========================================================================
 >   // TODO: ZONA DE TRABAJO DEL ALUMNADO
 >   // 1. Validar si 'a' es cero (caso degenerado a primer grado).
 >   // 2. Calcular el discriminante: discriminante = b*b - 4*a*c;
 >   // 3. Evaluar mediante estructuras condicionales (if - else if - else):
 >   //      - Caso discriminante > 0: calcular x1 y x2 usando sqrt().
 >   //      - Caso discriminante == 0: calcular -b/(2a)
 >   //      - Caso discriminante < 0: advertir que no existen soluciones reales.
 >   // =========================================================================
>
 >   return 0;
>}
>```
