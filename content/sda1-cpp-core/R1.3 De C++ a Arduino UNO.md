# 1. ¿Qué es Arduino?
Arduino es una plataforma de desarrollo electrónico que permite programar dispositivos capaces de interactuar con el mundo físico. Esta compuesto por:

- **El Hardware (la placa)**: Un circuito impreso que incluye un microcontrolador (como el ATmega328P en el clásico _Arduino Uno_) y pines de entrada/salida para conectar componentes.
- **El Software (Arduino IDE)**: Un entorno donde se escribe el código de instrucciones (C y C++) que luego se transfiere a la placa mediante un cable USB.


[Existen muchos modelos de placas Arduino](https://lab.bricogeek.com/tutorial/guia-de-modelos-arduino-y-sus-caracteristicas/introduccion), pero la más popular es Arduino UNO R3
![[recursos/arduino uno.png]]
- **1.** **Microcontrolador**: este es el cerebro de un Arduino, y es el componente en el que cargamos los programas. Piensa en ello como una pequeña computadora, diseñada para ejecutar solo un número específico de cosas.
- **2.** **Puerto USB:** se utiliza para conectar la placa Arduino a un ordenador.
- **3.** **Chip USB a** serie: el USB a serie es un componente importante, ya que ayuda a traducir los datos que provienen de, por ejemplo, una computadora al microcontrolador a bordo. Esto es lo que hace posible programar la placa Arduino desde su computadora.
- **4.** **Pins digitales** - pines que utilizan lógica digital (0,1 o BAJO/ALTO). Comúnmente utilizado para interruptores y para encender / apagar un led.
- **5.** **Pines** analógicos: pines que pueden leer valores analógicos en una resolución de 10 bits (0-1023).
- **6.** **Pines de 5V / 3.3V**: estos pines se utilizan para alimentar componentes externos.
- **7.** **GND** - también conocido como `ground`. Se utiliza para completar un circuito, donde el nivel eléctrico está a 0 voltios.
- **8.** **VIN** - significa Voltage In, donde se puede conectar fuentes de alimentación externas.

## 2.2 Estructura de un sketch

El requisito mínimo absoluto de un programa de Arduino (Sketch) es el uso de dos funciones: `void setup()` y `void loop()`.

- `void setup()` - esta función solo se ejecuta una vez, cuando el Arduino está encendido. Aquí definimos cosas como el modo de un pin (entrada o salida), la tasa de transmisión en serie o la inicialización de una biblioteca.
- `void loop()`- aquí es donde escribimos el código que queremos ejecutar una y otra vez, como encender / apagar una lámpara basada en una entrada, o para realizar una lectura de sensor cada X segundo.

Las funciones anteriores **siempre** son necesarias en un sketch de Arduino, pero por supuesto puedes agregar varias funciones más, lo que es útil para programas más largos.

Para poder escribir un programa para Arduino necesitamos un **entorno de desarrollo** y el más utilizado es el **IDE de Arduino**.

El IDE de Arduino nos permite escribir un programa (sketch), compilar ese programa en código máquina y, finalmente, enviar ese código máquina a la placa Arduino.

>[!info]
>Los IDE de Arduino están disponibles para su descarga gratuita en la [página de descargas de arduino](https://www.arduino.cc/en/software/).

## 2.3 Flujo de trabajo típico

Para cargar código en una placa de Arduino usando el IDE, normalmente se hace lo siguiente:

**1. Selecciona la placa**: sin seleccionar la placa correcta, simplemente no puede usar su tablero. La instalación se realiza directamente en el IDE, y es una operación rápida y fácil.
![[recursos/seleccion placa.png]]

**2. Crear un nuevo sketch** - un sketch es su archivo de programa principal. Aquí escribimos un conjunto de instrucciones que queremos ejecutar en el microcontrolador.
![[../../../Pasted image 20261020183002.png]]

**3. Compilar(verificar) el sketch:**: el código que escribimos no es exactamente como se ve cuando se carga en nuestro Arduino: compilar código significa que lo verificamos por errores y lo convertimos en un archivo binario (1s y 0s). Si algo falla, lo conseguirás en la consola de errores.

**4. Cargar el sketch a la placa**: una vez que la compilación tenga éxito, el código se puede cargar en la placa. En este paso, conectamos la placa a la computadora físicamente y seleccionamos el puerto serie correcto.

**5. Monitor serial (opcional)** - para la mayoría de los proyectos de Arduino, es importante saber lo que está pasando en la placa. La herramienta Monitores en serie disponibles en todos los IDE permite que los datos se envíen desde su placa a su computadora.
